# ``ARCFirebaseCore``

Core Firebase configuration and utilities for ARC Labs Studio apps.

## Overview

ARCFirebaseCore provides the foundation for all Firebase integrations in your app. It handles Firebase initialization, configuration management, and common utilities.

## Key Features

- **Single initialization**: Configure Firebase once, use everywhere
- **Error handling**: Unified error types across all Firebase modules
- **Multi-app support**: Works seamlessly across multiple ARC Labs apps
- **Thread-safe**: Safe to call from any thread
